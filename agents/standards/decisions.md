# Architecture Decision Records

Significant architectural decisions SHOULD use ADRs.

## Location

```text
docs/architecture/decisions/
```

## Examples

```text
0001-use-laravel-sanctum.md
0002-use-postgresql-vector.md
0003-adopt-temporal-workflows.md
```

## ADR Structure

```text
Title
Status
Context
Decision
Alternatives
Consequences
Migration
Rollback
```
