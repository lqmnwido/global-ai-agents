# Design System

Frontend projects MUST use their existing design system.

## Inspect

Agents MUST inspect:

```text
Existing layouts
Components
Typography
Spacing
Colors
Forms
Buttons
Tables
Modals
Navigation
Loading states
Empty states
Error states
```

## Rules

* Do not create visually inconsistent components when reusable components exist.
* Where a company-wide design system exists, projects SHOULD depend on it rather than recreating components independently.
