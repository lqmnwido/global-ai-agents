# AI Agent Rules

## Agents MUST

* Read AGENTS.md before modifying the project.
* Inspect the repository before proposing architecture.
* Follow existing patterns.
* Explain significant architectural changes.
* Minimize unrelated modifications.
* Preserve working behavior.
* Test their implementation.
* Report failed validation honestly.
* Identify assumptions.
* Identify untested areas.
* Never claim success without evidence.

## Agents MUST NOT

* Invent project structures without inspecting the repository.
* Replace working architecture simply because another architecture is preferred.
* Install arbitrary dependencies.
* Modify production systems without authorization.
* Delete data without explicit authorization.
* Bypass authentication or authorization.
* Disable tests merely to make CI pass.
* Hide errors.
* Fabricate test results.
* Fabricate commands that were supposedly executed.
